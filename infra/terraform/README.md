# AWS deployment

This Terraform stack creates the low-cost pilot MVP on one EC2 instance with an Elastic IP, Docker Compose, React served by Nginx, FastAPI, PostgreSQL, and public TCP listeners for the custom GPS gateway.

It does not use Traccar.

## Deploy

1. Push this repository to a private or public Git repository reachable by EC2.
2. Copy `terraform.tfvars.example` to `terraform.tfvars` and set `repository_url` and a restricted `admin_cidr`.
3. Run:

```bash
terraform init
terraform plan
terraform apply
```

4. Open the `api_url` output in a browser for the pilot dashboard.
5. Read the `elastic_ip`, `teltonika_tcp_endpoint`, and `concox_tcp_endpoint` outputs.
6. Configure devices with the Elastic IP and port `5001` or `5002`.

The database and JWT secrets are generated by Terraform and passed only through EC2 user data. Protect the Terraform state because it contains those generated secrets.

This account currently lacks permission to create an IAM role, so SSM is not enabled by this stack. Add an EC2 key pair and set `ssh_key_name` if SSH administration is required.

This MVP is intended for a small pilot fleet. It keeps the custom TCP server continuously running on EC2; Lambda/API Gateway can be added later for asynchronous alerts and reports. For production, migrate PostgreSQL to Amazon RDS, put the API behind an ALB/HTTPS certificate, add an SSM role, and use a CI/CD image registry instead of building directly on the instance.
