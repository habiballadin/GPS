# AWS deployment

This is the only Terraform deployment path intended for the AWS Free Tier / credit-conserving pilot. It creates one `t3.micro` EC2 instance, a 20 GB gp3 boot volume, a static Elastic IP, Docker Compose, FastAPI, PostgreSQL, and public TCP listeners for the custom GPS gateway. No load balancer, NAT gateway, RDS/Aurora, ECS, Redis, or paid observability resources are created.

It does not use Traccar.

## Deploy

1. Push this repository to a private or public Git repository reachable by EC2.
2. Copy `terraform.tfvars.example` to `terraform.tfvars` and set `repository_url` and a restricted `admin_cidr`.
3. Run:

```bash
terraform init
terraform plan
terraform apply
```

4. In the EC2 console, copy the instance's Elastic IP address.
5. Configure devices with that Elastic IP and port `5001` or `5002`.

The database and JWT secrets are generated by Terraform and passed only through EC2 user data. Protect the Terraform state because it contains those generated secrets.

The stack creates a minimal IAM role/profile for Systems Manager access. Add an EC2 key pair and set `ssh_key_name` only if SSH administration is required.

This MVP is intended for a small pilot fleet. An Elastic IP incurs public IPv4 charges on current AWS pricing, but is retained because GPS devices need a stable endpoint; it is the only intentionally chargeable infrastructure item. Credits can apply to eligible usage, but AWS billing should be monitored before and after deployment. For production, use the separately gated `platform/` stack only after approving its recurring costs.
